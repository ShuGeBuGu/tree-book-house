怎么创建 Token？＋

Classic Token 只需勾选 public_repo；想使用更细粒度的权限时，可以按下面步骤创建 Fine-grained Token。

  1. 打开 GitHub → 右上角头像 → Settings → Developer settings → Personal access tokens → Fine-grained tokens。
  2. 点击 Generate new token，Repository access 选择 Only select repositories，只勾选你的网站仓库。
  3. Permissions → Repository permissions → 找到 Contents，设为 Read and write；Metadata 保持 Read-only。
  4. 生成后复制以 github_pat_ 开头的 Token，粘贴到上面。它只用于向这个仓库提交照片。

Token 就像一把钥匙。不要发给别人；如果怀疑泄露，去 GitHub 页面 Revoke 掉再重新生成即可。

    A NOTE ABOUT “FOREVER”

    关于“照片永远不会过期”

    网站是纯静态页面，没有会过期的图床链接。只要 GitHub 仓库还在、GitHub Pages 正常服务，照片就一直能访问。也建议你保留一份原始照片备份，那是最踏实的一层保险。

    SECURITY

    关于安全

    Token 只保存在你自己的浏览器里，除非你勾选“记住配置”。使用 Fine-grained Token，并只授权当前仓库的 Contents 读写权限。网站访客没有 Token，无法修改照片。
